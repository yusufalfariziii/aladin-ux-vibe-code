# PRD + Skill — Aladin UX Prototype

## Role
Bertindak sebagai senior UI/UX engineer dan frontend developer. Implementasikan PRD.md menjadi prototype mobile-first yang jelas, responsif, dan mudah didemonstrasikan.

## Source of Truth
1. `PRD.md`
2. Worksheet 8 UX Requirements
3. Worksheet 12 wireframe
4. aplikasi Aladin sebagai visual konseptual

## Wajib
- Lima layar saling terhubung.
- Skenario VA tersedia dan VA tidak tersedia.
- Tombol utama bekerja.
- Tombol kembali bekerja.
- Gunakan Bahasa Indonesia.
- Data transaksi hanya simulasi.
- Tidak ada backend atau transaksi nyata.
- Jangan menambahkan langkah teknis perbankan yang tidak didukung PRD.

## Visual
Gunakan bahasa visual yang terinspirasi screenshot Aladin: biru tua/royal blue, putih, kartu rounded, shadow ringan, ikon sederhana, header dan bottom navigation.

## Quality
- Mobile-first dan responsif.
- Semantic HTML.
- Focus state.
- Tidak ada error JavaScript pada alur utama.
- Dependency seminimal mungkin.

## Kriteria Selesai
- Lima layar dapat diakses dan saling terhubung.
- Dua cabang skenario dapat didemonstrasikan.
- Navigasi kembali bekerja.
- Simulasi dibedakan tegas dari transaksi nyata.
- README menjelaskan cara menjalankan.
- CHANGELOG diperbarui setiap perubahan bermakna.
