# Web App — Aladin UX (PRD Only)

Aplikasi frontend React + Vite untuk demonstrasi konsep pengalaman pembayaran Virtual Account.

## Jalankan lokal
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

Source code berada di `src/`. Hasil build dibuat pada folder `dist/`.

Data transaksi hanya simulasi. Tidak ada backend atau transaksi perbankan nyata.
