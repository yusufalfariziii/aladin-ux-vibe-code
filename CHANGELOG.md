- Mengembangkan beranda, Bayar & Beli, Virtual Account, konfirmasi simulasi, VA tidak tersedia, dan pilihan metode alternatif.
- Menghubungkan navigasi antarlayar dan feedback untuk aksi simulasi.

- Memperbarui README dengan struktur source code, teknologi, fitur, dan cara menjalankan project.
- Menyesuaikan PRD dan PRD + Skill dengan implementasi React + Vite.

### Notes
- Aplikasi masih berupa frontend konseptual tanpa backend atau integrasi pembayaran nyata.
- Data merchant, nomor VA, dan nominal adalah data simulasi.
- Status deployment versi React + Vite perlu diverifikasi dari GitHub Actions setelah workflow selesai.
